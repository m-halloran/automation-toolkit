# Allowlist for C:/. Listed last. Rooted at the volume root.
#
# Allowlist rather than denylist because this is the OS volume: Windows and its
# installers create directories here constantly, so a denylist would back up
# anything new by default and you would find out when F: and G: filled up. This
# way a new application is missed until it is added, which is the cheaper
# failure. The trailing "- **" also keeps rclone out of /Windows and
# /Program Files entirely rather than walking them.

- .ssh/**
- **/.credentials.json
