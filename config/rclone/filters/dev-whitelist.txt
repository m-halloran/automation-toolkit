# Allowlist for D:/dev. Listed last, after d-blacklist.txt.
#
# D:/dev is manually-managed tool binaries, nearly all re-downloadable, so it
# is denied wholesale at the bottom and the "+" rules rescue the paths holding
# real settings. Version numbers are globbed on purpose: a literal
# "librewolf-149.0-1" stops matching the day you update, and fails silently in
# the dangerous direction.
